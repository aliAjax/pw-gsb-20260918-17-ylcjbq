# hxyfront-62003 法医昆虫学样本记录

用于法医昆虫学检材管理的前端工具：记录采样地点、环境温度、尸体暴露阶段、昆虫种类、发育阶段、采样时间、保存方式与鉴定备注，提供样本批次列表、发育阶段筛选、温度记录图、案件样本关联页和单样本详情卡片。

## 批次复核规则

同一案件（批次）内：

1. 样本按**采样时间排序**，发育阶段（卵 → 幼虫 → 蛹 → 成虫）**不能倒退**；
2. 连续样本**温差超过 8℃** 时：
   - 两端样本均已填写**保存方式** → 批次通过，相关样本**标记待复检**（温度图与列表同步警示）；
   - 任一端未填写保存方式，或存在发育阶段倒退 → **整批拒绝，原数据不变**，拒绝原因永久留痕；
3. **复检确认只解除待复检标记**；样本原始值、字段调整痕迹（原值 → 新值 + 原因）与历次拒绝原因全部保留；
4. 复核 / 确认 / 调整后，批次列表徽标、详情卡片与温度图同时更新。

## 技术栈

React 19 + Vite 7 + TypeScript（无额外 UI 依赖，温度图为内联 SVG），状态持久化到 localStorage。
